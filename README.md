# ChillRain随想
随便想想，想到什么写什么
## 关于模组内容
本模组没有任何前置，主要内容都以联动的形式出现。
### 龙之进化联动
目前内容：添加了混沌龙套装，性能已经超过了1.12的混沌龙套装
未来可能的内容：移植创造通量容器
### 植物魔法联动
目前内容：添加了额外植物学的大师魔力之戒，征服宝石。添加了植物学拓展的精灵祭坛（WIP状态，但是可以正常使用，火花需要放聚集符文）
## 可配置项
使用某一些版本的植物魔法可能产生物品重复注册问题，可以在配置文件中关闭植物魔法联动。
