# ChillRain随想
随便想想，想到什么写什么
## 关于模组内容
本模组没有任何前置，主要内容都以联动的形式出现。
### 龙之进化联动
目前内容：添加了混沌龙套装，性能已经超过了1.12的混沌龙套装
未来可能的内容：移植创造通量容器
### 植物魔法联动
目前内容：添加了额外植物学的大师魔力之戒，征服宝石。添加了植物学拓展的精灵祭坛（WIP状态，但是可以正常使用，火花需要放聚集符文）
## 可配置项
使用某一些版本的植物魔法可能产生物品重复注册问题，可以在配置文件中关闭植物魔法联动。

## 一些可能有人想问的问题
Q：为什么所有的物品都没有合成配方？\n
A：本模组最初是用在我们私人服务器上的，都是通过CRT添加合成配方，所以没有。\n
Q：为什么出现了某个植物魔法的物品注册两次？\n
A：有一些版本的植物魔法物品注册逻辑太提前了，会产生这样的问题，作者开发的时候使用的是GTNH1.9版本的植物魔法。尽量使用这个版本。\n
